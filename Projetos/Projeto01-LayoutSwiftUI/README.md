# Projeto 01 — Composição de layout com SwiftUI

Exercício introdutório de construção de interfaces declarativas com SwiftUI. A tela organiza quatro blocos coloridos em uma composição 2 × 2, utilizando `VStack`, `HStack`, `Spacer` e espaçamento.

## Funcionalidades
- Exibe quatro retângulos de 100 × 100 pontos.
- Organiza azul e vermelho na linha superior, verde e laranja na linha inferior.
- Demonstra alinhamento e distribuição dos elementos.

## Tecnologias
Swift, SwiftUI.

## Arquivos
- `ContentView.swift` — interface.
- `Desafio01App.swift` — ponto de entrada.
- `03 - [PDF] Swift - Tudo são Views.pdf` — material de apoio.

## Executar
Crie um projeto iOS App com interface SwiftUI no Xcode, adicione os dois arquivos Swift ao target e execute em um simulador ou iPhone compatível. Esta pasta não contém um projeto Xcode completo; não são necessários serviços externos ou assets.
