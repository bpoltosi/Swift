# Projeto 02 — Cartão de apresentação HackaTruck

Exercício de composição de uma interface SwiftUI com imagem e textos, apresentando a identificação do HackaTruck e informações do programa em uma disposição horizontal.

## Funcionalidades
- Imagem circular com contorno e sombra.
- Título HackaTruck e textos “77 Universidades” e “5 regiões do Brasil”.
- Hierarquia visual com tipografia, cores e espaçamento.

## Tecnologias
Swift, SwiftUI, `Image`, `VStack` e `HStack`.

## Arquivos e recursos
- `ContentView.swift` — interface.
- `Desafio02App.swift` — ponto de entrada.

O código referencia `Image("hackatruck")`. Adicione ao projeto um image set com esse nome em `Assets.xcassets` (ou ajuste a referência no código). O asset não está versionado nesta pasta.

## Executar
Crie um projeto iOS App com SwiftUI no Xcode, adicione os fontes ao target, inclua o asset `hackatruck` e execute.
