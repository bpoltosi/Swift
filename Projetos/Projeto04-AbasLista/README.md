# Projeto 04 — Abas e lista de itens

Aplicativo de estudo de navegação com `TabView` e apresentação de coleções com `List`. Reúne páginas ilustrativas com diferentes cores e símbolos e uma aba com uma lista de itens.

## Funcionalidades
- Quatro abas.
- Três telas com fundos rosa, azul e cinza e ícones SF Symbols.
- Lista com nomes e símbolos.
- Modelo `ItemLista` identificado por UUID.

## Tecnologias
Swift, SwiftUI, `TabView`, `NavigationView`, `List`, `ForEach` e SF Symbols.

## Arquivos e materiais
