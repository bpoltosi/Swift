# Desafio 01 — Composição de layout com SwiftUI

Exercício introdutório de construção de interfaces declarativas com **SwiftUI**. A tela organiza quatro blocos coloridos em uma composição 2 × 2, usando pilhas horizontais e verticais para distribuir os elementos.

## Funcionalidades

- Exibe quatro retângulos de 100 × 100 pontos.
- Organiza azul e vermelho na linha superior, verde e laranja na linha inferior.
- Usa `VStack`, `HStack`, `Spacer` e `padding` para controlar alinhamento e espaçamento.

## Tecnologias

- Swift
- SwiftUI

## Arquivos

- `ContentView.swift` — implementação da interface.
- `Desafio01App.swift` — ponto de entrada do aplicativo SwiftUI.

## Executar

Os arquivos deste diretório são as fontes do exercício; não há um projeto `.xcodeproj` ou `.xcworkspace` versionado nesta pasta. Para executá-lo isoladamente, crie um projeto **iOS App** com interface SwiftUI no Xcode, adicione os dois arquivos ao target e execute em um simulador ou iPhone compatível.

Não são necessários serviços externos, permissões especiais ou recursos de imagem.
