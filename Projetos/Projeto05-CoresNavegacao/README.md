# Projeto 05 — Seleção de cor e navegação

Aplicativo SwiftUI que recebe um texto, permite selecionar uma cor e um símbolo e navega para uma tela de resultado que utiliza a seleção feita pelo usuário.

## Funcionalidades
- Campo de texto.
- Grade com quatro opções de cor: vermelho, azul, cinza e roxo.
- Cada cor é associada a um símbolo SF Symbols.
- Navegação para uma segunda tela ao selecionar uma opção.
- Exibição do texto informado, da cor de fundo e do símbolo selecionado.

## Tecnologias
Swift, SwiftUI, `@State`, `LazyVGrid`, `NavigationView` e `NavigationLink`.

## Arquivos
- `ContentView.swift` — seleção e tela de resultado.
- `Desafio_02App.swift` — ponto de entrada.

## Executar
Crie um projeto iOS App com SwiftUI no Xcode, adicione os arquivos ao target e execute em simulador ou iPhone. Não depende de API ou backend.
